# Golden Hour

Професійний веб-сайт для фотографічної студії, що спеціалізується на портретній та подієвій фотографії.

## Про проєкт

**Golden Hour** — це сучасна посадкова сторінка фотографічної студії, яка демонструє портфоліо, послуги та переваги. Проєкт вирішує завдання:

- 📸 Презентації робот студії та демонстрації портфоліо
- ℹ️ Надання інформації про послуги та переваги
- 💬 Збір зворотних звітків та відгуків клієнтів
- ❓ Відповіді на часті запитання
- 📧 Контактування клієнтів для замовлень

## Функціональність

- **Hero Section** — привітальна секція з привабливим дизайном
- **About Us** — інформація про студію та її команду
- **Benefits** — переваги та особливості послуг
- **Portfolio** — галерея робіт з фільтруванням
- **Feedbacks** — відгуки клієнтів (слайдер)
- **FAQ** — часто задавані питання (акордеон)
- **Contacts** — форма для зв'язку з валідацією
- **Success Modal** — модальне вікно підтвердження надсилання форми
- **Responsive Design** — адаптивний дизайн для всіх пристроїв

## Технології

### Frontend
- **HTML5** — семантична розмітка
- **CSS3** — сучасне стилізування (PostCSS)
- **JavaScript (ES6+)** — логіка взаємодії

### Бібліотеки та інструменти
- **Vite** — швидкий збирач модулів
- **Swiper** — каруселі та слайдери
- **Accordion.js** — компонент акордеону
- **SimpleLightbox** — лайтбокс для галереї
- **Axios** — HTTP клієнт для запитів
- **iziToast** — сповіщення і toast-повідомлення
- **Modern Normalize** — нормалізація стилів
- **PostCSS** — постпроцесор CSS з сортуванням медіа-запитів
- **Prettier** — форматування коду

## Встановлення та запуск

### Вимоги
- Node.js (версія 16+)
- npm або yarn

### Кроки для запуску

1. **Клонування репозиторію:**
   ```bash
   git clone https://github.com/yanamikha/team_project_js.git
   cd team_project_js
   ```

2. **Встановлення залежностей:**
   ```bash
   npm install
   ```

3. **Запуск у режимі розробки:**
   ```bash
   npm run dev
   ```
   Сайт буде доступний за адресою `http://localhost:5173` (або іншого порту, що вказує Vite)

4. **Збирання для продакшену:**
   ```bash
   npm run build
   ```
   Результати будуть у папці `dist/`

5. **Перегляд збудованого проєкту:**
   ```bash
   npm run preview
   ```

6. **Розгортання на GitHub Pages:**
   ```bash
   npm run deploy
   ```
